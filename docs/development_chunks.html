📋 StockSignal AI – Development Chunks

18 executable chunks to build, test, and ship the product incrementally.

Chunk 1: Foundation & Environment Setup

Dependencies: None

Goal

Get the Next.js app running locally with TypeScript, Tailwind, and linting.

Key Tasks

  • Initialize Next.js 14 with App Router + TypeScript
  • Install and configure Tailwind CSS
  • Set up ESLint
  • Create .env.example
  • Verify npm run dev

Acceptance Criteria

  • npm run dev serves at localhost:3000
  • npm run lint passes
  • npm run typecheck passes

Chunk 2: Shared Types & Utilities

Dependencies: Chunk 1

Goal

Define TypeScript types and helper functions used across the app.

Key Tasks

  • Create types: StockQuote, SignalResult, MarketStatus
  • Symbol validation & sanitization utilities
  • Price formatting utilities (decimal precision)
  • Timezone utilities (UTC ↔ IST)

Acceptance Criteria

  • sanitizeSymbol('RELIANCE.NS') returns normalized symbol
  • sanitizeSymbol('INVALID!') throws error
  • formatPrice(1234.5, 'RELIANCE.NS') returns '1234.50'

Chunk 3: Market Status Service

Dependencies: Chunk 2

Goal

Implement accurate market open/close detection for IST, including weekends and holidays.

Key Tasks

  • Implement isMarketOpen() using Intl.DateTimeFormat
  • Add market holidays list
  • Write unit tests for boundary conditions

Acceptance Criteria

  • Returns OPEN at 09:30 IST weekday
  • Returns CLOSED at 09:14 IST weekday
  • Returns CLOSED on weekends/holidays
  • All unit tests pass

Chunk 4: API Infrastructure

Dependencies: Chunk 2

Goal

Create API route structure and database clients.

Key Tasks

  • Create Supabase client singleton
  • Create Upstash Redis client singleton
  • Create /api/health and /api/market/status
  • Set up CORS headers

Acceptance Criteria

  • GET /api/health returns { status: 'ok' }
  • GET /api/market/status returns open/closed state
  • CORS headers present on all responses

Chunk 5: Data Layer – Yahoo Finance Integration

Dependencies: Chunk 4

Goal

Fetch live and historical stock data with resilience and caching.

Key Tasks

  • Implement getLiveQuote(symbol)
  • Implement getHistoricalData(symbol, timeframe)
  • Add exponential backoff wrapper
  • Add Redis caching (5min quotes, 1hr historical)
  • Implement fallback chain

Acceptance Criteria

  • getLiveQuote('RELIANCE.NS') returns quote data
  • Data cached in Redis with TTL
  • Circuit breaker opens after 5 failures

Chunk 6: Technical Indicators Service

Dependencies: Chunk 2, 5

Goal

Calculate RSI, MACD, Bollinger Bands, and Moving Averages.

Key Tasks

  • Implement calculateRSI(prices, period)
  • Implement calculateMACD(prices)
  • Implement calculateBollingerBands(prices, period)
  • Implement calculateMovingAverages(prices, periods)
  • Add unit tests with known values

Acceptance Criteria

  • RSI matches expected value (±0.01)
  • MACD crosses signal line correctly
  • Bollinger Bands contain 95% of price data
  • All unit tests pass

Chunk 7: Signal Generation Service

Dependencies: Chunk 6

Goal

Generate buy/sell/hold signals with confidence scores and AI reasoning.

Key Tasks

  • Implement signal generation logic
  • Implement confidence scoring algorithm
  • Add mock AI reasoning generator
  • Implement getTopSignals()
  • Add Redis caching (10min TTL)

Acceptance Criteria

  • Returns one of 5 signal types
  • Confidence 0-100
  • Non-empty reasoning string
  • Signals cached in Redis

Chunk 8: Signal API Route

Dependencies: Chunk 3, 5, 7

Goal

Create /api/signal/[symbol] with market status awareness.

Key Tasks

  • Symbol validation & sanitization
  • Fetch quote + calculate signal
  • Tag response with marketStatus and isEOD
  • Zero out change when market closed
  • Error handling for invalid symbols/API failures

Acceptance Criteria

  • GET /api/signal/RELIANCE.NS returns valid response
  • When closed: isEOD = true, change = 0
  • Invalid symbol returns 400
  • API failure returns 503
