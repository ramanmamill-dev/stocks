2. Local Development (Zero Config)

If you just want to try the app without database/cache setup, skip to step 6.

git clone https://github.com/<your-username>/stocks.git
cd stocks
cp .env.example .env.local
npm install
npm run dev
Note: Without Supabase and Redis, the app runs in degraded mode. Signals still work from yfinance, but watchlists won't persist and caching is in-memory only.

3. Supabase Setup (Free Tier)

Supabase provides PostgreSQL for storing watchlists and cached signals.

Steps:

  1. Create a free account at supabase.com
  2. Click "New Project" and fill in:
    • Name: stocksignal-ai
    • Database Password: Choose a strong password (save it!)
    • Region: Singapore (closest to India)
  3. Wait for project creation (~2 minutes)
  4. Navigate to Project Settings → API and copy:
    • NEXT_PUBLIC_SUPABASE_URL
    • anon public key
  5. Run migrations in the SQL Editor: 
    -- Open src/lib/supabase/migrations/001_watchlists.sql and run it
-- Then 002_cached_signals.sql
-- Then 003_screener_presets.sql
  6. Enable Row Level Security (RLS) on all three tables

4. Upstash Redis Setup (Free Tier)

Upstash provides managed Redis for caching and rate limiting.

Steps:

  1. Create a free account at upstash.com
  2. Click "Redis Database" → "Create Database"
  3. Choose:
    • Name: stocksignal-cache
    • Region: Singapore
    • TLS: Enabled
  4. Copy the REST URL and Token

7. Deploy to Render.com

Render.com provides a free tier (512MB RAM, 0.1 CPU) with Singapore region.

Automated Deploy:

  1. Push to GitHub (main branch autodeploys)
  2. Go to render.com → "New" → "Web Service"
  3. Connect your GitHub repo
  4. Render auto-detects render.yaml
  5. Set these environment variables in the Render dashboard:
    • NEXT_PUBLIC_SUPABASE_URL
    • NEXT_PUBLIC_SUPABASE_ANON_KEY
    • UPSTASH_REDIS_URL
    • UPSTASH_REDIS_TOKEN
  6. Render builds and deploys automatically
Pro tip: Set up a custom domain in the Render dashboard under Settings → Custom Domains.

8. Keep-Alive Setup (Free Tier)

Render free services sleep after 15 minutes of inactivity.

Prevent sleeping during business hours:

  1. Go to cron-job.org (free)
  2. Create a new cron job:
    • URL: https://<your-app>.onrender.com/api/health
    • Schedule: Every 10 minutes
    • Time range: 03:30 - 08:30 UTC (9 AM - 4 PM IST)

10. Troubleshooting

Build fails with "out of memory"

NODE_OPTIONS="--max-old-space-size=512" npm run build

Redis connection errors

Ensure UPSTASH_REDIS_URL and UPSTASH_REDIS_TOKEN are correct. The app will still work without Redis (degraded performance).

Supabase connection errors

Verify the URL and key are correct. RLS policies must be enabled but the app works without auth for public data. Ensure migrations were run.

yfinance rate limiting

The app auto-retries 3x with exponential backoff, then falls back to Indian-Stock-Market-API, then to cached data.

Port 3000 already in use

npx kill-port 3000
